# Contribuir a YaskCode Slides

Gracias por contribuir a este catálogo educativo.

Antes de enviar una presentación:

1. Lee la [guía de envío](SUBMISSION_GUIDE.md).
2. Completa una copia de [metadata-template.yml](metadata-template.yml).
3. Incluye la [diapositiva de autoría](templates/AUTHORSHIP_SLIDE.md).
4. Entrega el [formulario de autorización](templates/PUBLICATION_AUTHORIZATION.md).
5. Abre un Pull Request y completa todo el checklist.

## Autoría pública

Los nombres completos de todas las personas autoras se publicarán. LinkedIn, GitHub y ORCID son opcionales y solo se mostrarán con consentimiento.

## Revisión

Un envío no será publicado hasta verificar autoría, autorización, fuentes, derechos de terceros, privacidad, accesibilidad y declaración de uso de IA. No incluyas teléfonos, correos personales, documentos de identidad ni otros datos sensibles.
